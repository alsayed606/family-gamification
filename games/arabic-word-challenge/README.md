# تحدي الكلمات العربية

لعبة ويب عربية تنافسية بين فريقين (أزرق/أحمر): تُعرض حروف كلمة مبعثرة،
ويتسابق الفريقان على استخراجها. للاستخدام في المسابقات والفعاليات على شاشة
عرض يديرها مشرف. جزء من [Family Gamification Hub](../../README.md).

## التشغيل

```bash
npm install       # من جذر المستودع
npm run awc:dev    # تطوير (Vite + HMR)
npm run awc:test   # Vitest
npm run awc:build  # -> dist/ (يُرفع لـ git، راجع جذر المستودع)
```

## قواعد اللعب

- 10 جولات × 60 ثانية (قابلة للتعديل)، الإجابة الصحيحة 5 نقاط.
- **آلية الجرس:** أول فريق يضغط جرسه يوقف مؤقت الجولة ويحصل على 15 ثانية
  للإجابة. إجابة خاطئة أو انتهاء المهلة = يفقد دوره في الجولة. إذا أخطأ
  الفريقان تُكشف الكلمة وتنتهي الجولة.
- اختصارات المشرف: `1` جرس الفريق الأول، `2` الثاني، `Esc` لوحة المشرف.
- لا تتكرر كلمة داخل المباراة الواحدة.
- المقارنة بعد تطبيع النص: حذف التشكيل والتطويل، وتوحيد (أ إ آ ← ا)،
  (ى ← ي)، (ة ← ه)، (ؤ ← و)، (ئ ← ي)، وحذف الهمزة المفردة (`lib/arabic.ts`).

## ملاحظة أمنية

هذه نسخة **Phase 1**: تعمل بالكامل على العميل، الكلمة الصحيحة موجودة في
المتصفح، ولوحة المشرف غير محمية بمصادقة حقيقية. مقبول للعرض على شاشة واحدة
يديرها مشرف موثوق؛ **غير مقبول** للعب عن بُعد أو لأي نتائج رسمية.

## Phase 2 — عند الطلب

خادم Node.js + Express + PostgreSQL/Supabase: التحقق من الإجابة على الخادم
فقط (لا تُرسل الكلمة الصحيحة للعميل قبل انتهاء الجولة)، جداول
`words`/`matches`/`rounds`/`admins`، RLS في Supabase (قراءة عامة، كتابة
لدور `admin` فقط)، مصادقة مشرف حقيقية، وتحديد معدل الطلبات على مسار
الإجابة. عند التنفيذ، تُستبدل `lib/storage.ts` بطبقة تتحدث مع الـ API دون
تغيير أي شاشة أو hook.

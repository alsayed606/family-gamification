# 🎮 دليل نظام العائلة التفاعلي

## ما هو المشروع؟

نظام ويب **متكامل وحقيقي** للعائلة يحتوي على:

| الميزة | الوصف |
|--------|--------|
| 🎯 نظام نقاط | كسب XP و coins من خلال المهام |
| 📊 مستويات | ارفع مستواك مع النقاط |
| ✓ مهام يومية | أكمل مهام واحصل على مكافآت |
| 🏆 لوحة ترتيب | تنافس مع أفراد العائلة |
| 🛍️ متجر | اشتري مكافآت بـ coins |
| 👑 إدارة كاملة | تحكم كامل بـ الأفراد والمهام |

---

## 🏗️ كيف يعمل؟

### 1️⃣ الدخول

- **الأب والأم:** ادخل مباشرة بدون PIN
- **الأطفال:** ادخل مع PIN شخصي

### 2️⃣ إكمال المهام

- شوف المهام المتاحة
- اضغط ✓ لإكمال المهمة
- اكسب XP و coins فورًا
- شوف الترتيب يتغير مباشرة

### 3️⃣ الارتقاء

كل 100 XP = مستوى جديد
المستوى يفتح محتوى ومزايا جديدة

### 4️⃣ الإدارة (للأب/الأم)

- أضف أفراد جدد
- أضف مهام جديدة
- راقب التقدم

## 🔌 التكنولوجيا

```
Frontend (العميل):
- HTML (الهيكل)
- CSS (التصميم Dark Gaming)
- JavaScript (التفاعل)

Backend (الخادم):
- Firebase Firestore (قاعدة البيانات)
- Realtime Updates (تحديثات فورية)
```

**كل الأفراد يرون التحديثات فورًا دون refresh!**

---

## 📁 الملفات الرئيسية

### `src/html/index.html`
الصفحة الرئيسية (الهيكل)

### `src/js/`
```
app.js              ← Controller رئيسي
firebase-config.js  ← Firebase + قاعدة البيانات
screens.js          ← الشاشات (Dashboard, Tasks, etc)
login.js            ← الدخول + PIN
auth.js             ← الجلسة
ui-utils.js         ← مساعدات UI
```

### `src/css/style.css`
التصميم (نيون + توهج + RTL)

### `data/seed.html`
إنشاء البيانات الأولية

## ✨ المميزات الخاصة

### Dark Gaming UI
- تصميم حديث (نيون + توهج)
- أسود من الناحية الجمالية
- أزرق/بنفسجي/ذهبي للتنبيهات

### Realtime Updates
- أكمل مهمة → النقاط تتحدث فورًا
- افتح في نافذتين → شوف الترتيب يتغير

### Confetti Effects
- كل مهمة محققة → احتفالية مؤثرات
- notifications عائمة
